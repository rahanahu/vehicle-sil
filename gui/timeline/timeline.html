Scenario timeline

Drop a timeline file here, or choose one with Open a file.

A timeline file is the JSON that vehicle_sil_launch run <configuration> --scenario <scenario> --timeline <file> writes. Nothing leaves this computer: the page reads the file in the browser.

Steps: a bar from start to end, a tick where the result was decided, a thin line on to a wait's limit. Shaded: the values a condition allows (green: it held; red: it did not; grey: not decided by it). Red dashed line: the failure. Grey on the right: after the end of the record. Drag across the chart to zoom in, double-click for the whole run; hover (or focus the chart and use the arrow keys) for the values at a time.
