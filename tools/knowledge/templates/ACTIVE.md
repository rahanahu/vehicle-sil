# Register of decisions that are valid now (shared file)

Only decisions listed here are instructions. An older document that is not listed is unjudged: check it against newer documents and Git before relying on it.
Each entry: the constraint in one sentence, its source (the user's decision and date, or a document), and the detail as a link plus the heading's wording. Remove an entry when Git carries the same constraint.
