# Unstable tests (local; shared file)

Tests that failed in CI without a link to the change under test. Read it when a check fails on a test that your change does not touch; add to it when you find a new one (what to do with the pull request is in `plans/RULES.md`).

One item per test: the test, the job, where and when it failed (pull request or main commit, run), what the failure said, the suspected cause (say when it is a guess), the owner stream. When a pull request fixes it, write which one. Delete the item when the fix has been on main for a week and the failure has not come back.
