# Unstable tests (local; shared file)

Tests that failed in CI without a link to the change under test. Read it when a check fails on a test that your change does not touch; add to it when you find a new one. Re-run the failed job once; if it passes, the change may merge.

One item per test: the test, the job, where and when it failed (pull request or main commit, run), what the failure said, the suspected cause (say when it is a guess), the owner stream. When it is fixed, say by which pull request; remove the item when it has not come back for a while.
